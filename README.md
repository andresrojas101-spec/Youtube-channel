# Biblia Channel

Fábrica automatizada del canal [Biblia Channel](https://www.youtube.com/@Bibliachannel-u1w): historias de la Biblia narradas en español.

- `episodes/`: guiones (uno por carpeta, `episode.json`)
- `pipeline/`: voz, imágenes, render, Shorts, miniaturas, subida y métricas
- `.github/workflows/`: producción y métricas en GitHub Actions
- `canal/`: configuración, estilo, backlog y aprendizajes
- `docs/`: páginas públicas (inicio, privacidad y condiciones)

Las instrucciones de los agentes están en `CLAUDE.md`.
